## Screens
1. **`planets`** — the planets ledger: table `# · Planet · Population (↑ growth) · Fact · Shd · Base · Wst · Prod · Space Dock · Notes` from `Q.ledger(S, playerId)` (sortable columns, selected-row highlight, click a row = jump to that colony on the galaxy screen: `Game.sel.star = id; Screens.go('galaxy')`), footer panels exactly like the original: **Spending costs** (Ships %, Spying %, Bases %, Security %), **Total income** (Trade BC, Planets BC), **Reserve BC**, the **tax slider** (0–200 per-mille of gross, readout "+n BC" = what reaches the reserve; order `tax {value}`; steps of 5), **Transfer** button (needs reserve > 0: click a planet row, choose an amount with a 0–100% slider of the reserve in a small dialog; order `transfer {planet, amount}`), OK. Add: security slider (order `security`), a max-pop column, and colour-coded warnings (waste, unrest, starving growth, idle factories).
2. **`fleets`** (+ **Specs** as a second tab/button): a grid with one row per star where you have ships (station tile with planet picture / "moving"), one column per design (name header, ship sprite + count per cell via `Gfx.Ships.sprite`), footer "Ship maintenance cost n BC/year" (`Design.maintenance`), buttons Specs / Scrap / OK. **Specs**: one row per design with count, name, stats SHIELD, BEAM DEF, ATT LVL, WARP, MISL DEF, HITS, SPEED (from `Design.stats`), weapons list text, specials text, cost; Scrap (confirm; order `scrapDesign {slot}` — warn it removes all ships of that design). Click a row = jump to the fleet's star.
3. **`mapoverview`** — the whole-galaxy overview with **Colonies / Environments / Minerals** modes and the Map Key legend, built on `MOO.UI.GalaxyMap.create(container, …)` (see `js/ui/galaxymap.js` for its API: `setMode`, `legend()`); Colonies mode shows empire flags + a lavender outline of the area you can reach (fuel range) and your scanner coverage; Environments mode letters/colours per planet type with green = colonisable now / red = not yet (use `E.mods.colonyFor`); Minerals mode per `planet.special`. Click a star → close and focus it on the galaxy screen. Keys C / E / M switch modes, Space/Esc/right-click = OK.
4. **`system`** (params `{star, from}`) — the full-screen star-system view: big lit planet (`Gfx.Planets.draw` animated; GPU variant when supported), the star glowing top-right in its colour (`Gfx.Space.drawStarSurface` / sprite), planet name + "<type> environment", fleets in orbit as animated ship sprites with counts, info box (PLANET SIZE (max pop), FACTORIES, WASTE, POPULATION, GROWTH — growth only for your planets) and the row of tiny icons (people / factories / bases / waste), shield label, stargate label, special notes. For unexplored stars show only what the original shows. Background `Gfx.Space.makeBackdrop`/`Gfx.Scenes.surface`. Click/any key closes.
Everything works from any game state via the dev URL (`?dev=1&screen=planets&turns=25`). Final reply per the common brief.
