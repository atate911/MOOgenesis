Document the exact shape in the file header (the military agent reads it — keep it stable).
2. **Scouts** (`send_scout`, §8.1): which idle scouts go where (lowest-index unexplored in-range planets, 1 ship per target…), `need_conquer` roll per 08 §3.5 (store `ctx.shared.needConquer`), per-difficulty rate `1/(8−diff)`.
3. **Colonisation** (§3): the free "conjured" colony ship — implement the spawn through a new order `aiColonyShip {planet}` that you register in `colonize.js` via `MOO.Sim.Orders.register` (validate: empire is AI, planet owned, spawn probability already rolled by the planner; adds one colony ship of the empire's colony design to the stationary fleet at that star via `Sim.Fleet.addShips`); probability `min(500, 0.4·TP)/500` per turn with the Simple/Easy throttle, Expansionist exemption, `flag_send_colony` logic; candidate list (type ≥ threshold, in fuel range, planet-index order), nearest colony-ship stack serves each candidate, whole stack **plus escorts** leaves (`fleetSend` orders; remember pure planners: track committed ships in `ctx.shared`). Quirks `fourthColonyShip`, colony-design-index bug etc. per the policy.
4. **`AI.onColonized(S, E, planet)`** — the hook `sim/turn.js` calls on the MAIN thread right after an AI colony is founded (it may mutate S; keep it tiny and deterministic: new-colony slider defaults per research/07 §2.2, `p.build` default etc.). Check `js/sim/fleet.js` `colonize` for what the human path does so you don't double up.
5. Tests (≥ 30): determinism & purity; threshold per Planetology level/race (Silicoid any); spawn probability Monte-Carlo vs formula at several TP values and at each difficulty; Expansionist exemption; candidate ordering; escort rule; 4th-curse quirk both ways; `need_conquer` odds per difficulty; scouts target choice; `onColonized`; plus a **150-turn AI-only game** (use `Sim.autoPlay`) for 6 seeds × difficulties asserting: AIs actually expand (not stuck at 1 colony), Simple/Easy expand slower than Hard/Impossible on average, Expansionist objectives lead others — report the medians at turns 25/50/100/150 compared with research/07 §1.5/§9.
