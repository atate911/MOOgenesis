**Read `briefs/_ui-common.md` first.** Spec: `research/06-ui-presentation-audio.md` §5.19 (High Council), §5.18 (spy scenes), §8 (endings), §12 (music cues), `research/05-diplomacy-events-victory.md` §5.9 (spy info screens), §6 (council flow), §8 (end states/presentations), `js/sim/council.js` / `js/sim/spy.js` (another agent writes them; read their headers when they appear; interrupt payload shapes are in DESIGN B5: `{type:'council', info}`, `{type:'councilResult', result}`, `{type:'spyStealChoice', candidates}`, `{type:'gameover', reason, winner}`), `Gfx.Scenes.council/ending`, `Gfx.Portraits`, `js/data/text.js` (`Data.text.epilogue`, `councilTitles` in `Data.names`).

## You own
`js/ui/council.js` (`MOO.UI.Council`), `js/ui/spyscenes.js` (`MOO.UI.Spy`), `js/ui/endings.js` (`MOO.UI.Endings`).

## API
1. **`MOO.UI.Council.show(interrupt) → Promise<vote>`** — the arched council chamber (`Gfx.Scenes.council`) with up to 6 alcove portraits, the pedestal hologram showing the current speaker, running tally text along the top ("n votes <name> | N votes total | m votes <name>"), message line at the bottom, music `Audio.Music.play('council')`. Flow: "Council convenes" → nomination → each empire votes in turn (their vote shown) → your vote prompt with numbered choices (1 candidate A / yourself, 2 candidate B, 0 abstain; keys + mouse) → tally. Return the value `Council.resolve` expects (see its header). **`MOO.UI.Council.result(interrupt)`** — shows the outcome; if you must decide, the Accept / Defy dialog (Y/N; defying = Final War warning) and the "no winner" message; hands the choice back as the module documents.
2. **`MOO.UI.Spy`** — `steal(interrupt) → Promise<pick>`: the espionage-success panel (target race header + planet picture, six field buttons for fields where they have techs you lack, candidates as a list with descriptions; Esc aborts), then the lab scene via `MOO.UI.TechScenes.breakthrough` if present; `sabotage(interrupt)`: pick a target colony on a mini-map, then Destroy factories / Destroy missile bases / Incite revolt buttons, result card with an explosion animation; `victimNotice(ev)`; `caught()` — the **Spies Caught** table (Yours / Theirs per contacted race, key C opens it from the galaxy screen: call it from the galaxy hotkeys? — export it and tell the lead). Music cues 15–17 equivalents (`Audio.Music.play(...)` if tracks exist).
3. **`MOO.UI.Endings.show(interrupt) → Promise`** — four endings from §8: **good** (council victory — you elected), **tyrant** (conquest), **funeral** (your empire destroyed — procession animation), **exile** (rival elected and you accepted — your ship drifting through parallax stars). Race-specific text from `Data.text.epilogue.victory.council|conquest[race]` / `defeat[race]` (with your leader name), `Gfx.Scenes.ending` backdrops (victory/defeat), ending music (`victory`, `defeat`), a closing GNN-style broadcast line, then "Return to title" (+ "Keep playing" when the rules allow). Skip with Space/Esc.
Test with fixtures from the console (e.g. `MOO.UI.Endings.show({reason:'conquest', winner:0})`, council info objects as documented by council.js).
