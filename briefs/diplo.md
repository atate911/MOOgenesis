## API (`MOO.Sim.Diplo`)
State: `S.diplo` (or per-pair data inside `E.relations[j]` — your choice, document it) holding for each ordered pair: `relation1` (current DP −100..+100), `relation2` (long-run base), `trust`, the four moods (`mood_treaty, mood_trade, mood_tech, mood_peace`), treaty (none/NAP/alliance/war/final war), trade (bc, percent), contact/ "gone" flags, spy/incident memory, ceasefire timers, `attackGift…` etc. exactly as §2 describes.
- Query: `init(S)`, `isAllied(S,a,b)`, `atWar(S,a,b)`, `hasContact(S,a,b)`, `status(S,a,b) → {treaty, treatyName, trade:{bc,percent}, attitude (DP), label (17-step ladder), trust, contact, canAudience}`, `tradeIncome(S,E)` (BC/turn after trade_percent incl. Human +25), `power(S,a)` helpers used by war checks.
- Turn hooks (called by `sim/turn.js`): `preTurn(S,R)` (mood tweaks, §4.3), `economyTurn(S,R)` (trade percent growth, treaty maintenance, relation drift toward `relation2`, §4.3), `turn(S,R) → interrupts[]` (contact detection & first-contact messages, AI-initiated proposals/threats/war declarations/peace requests toward the human as `{type:'diplomacy', from, kind, text:{personality,situation,vars}, options:[…], answer(fn)}` — the UI plays an audience; AI↔AI diplomacy and wars (§4.7, research/01 §5.7–5.8) resolved silently with news events `{type:'news', cat:'warDeclared'|'peaceTreaty'|'napSigned'|'allianceFormed'|'allianceBroken'|'tradeSigned'|'treatyBroken'|'tributePaid'…, race, race2, …}`).
- Player-initiated audience (UI): `menu(S, humanId, aiId) → {actions:[{id,label,enabled,options:[…]}]}` mirroring the original menu (Propose Treaty / Form Trade Agreement / Threaten-Break / Offer Tribute / Exchange Technology / Good Bye incl. counter-offers 'sweeteners'), `propose(S, humanId, aiId, proposal) → {accepted, reply:{situation, vars}, counter?, effects}` implementing the EXACT acceptance formulas, thresholds, random terms and mood/trust side effects of §4.4–4.5, `declareWar(S,a,b,reason)`, `breakTreaty`, tribute (BC/tech) via `Ground.techCandidates`/`Research.grant`, threats (§4.4), tech exchange value function (§1.10 of research/02 + §4.4).
- Orders to register on `MOO.Sim.Orders`: `diplomacy {to, act, …}` (so AI planners can use the same entry points), keep audience details out of Orders (UI calls the functions above directly).
- Incidents API for other modules: `Diplo.incident(S, kind, from, to, magnitude)` (spy caught, bio bombing, border violation (ships in orbit over a non-allied colony), broken treaty, war declaration, council vote effects …) with the DP deltas the research lists.
- Personality/objective effects must be implemented where the research says (reldiff table, act scaling, Honorable double trust loss, Erratic random war, objective-driven treaty breaking, Human bonuses, difficulty variables of §9 such as "AI breaks treaties", tribute etc.).
