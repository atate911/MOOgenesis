**Read `briefs/_ui-common.md` first.** Spec: `research/06-ui-presentation-audio.md` §5.12 (Research screen), §5.13 (scenes: choose next research, breakthrough, follow-up dialogs), `research/02-technology.md` §1 (how research works: six field sliders in 2% steps with locks, light-bulb = breakthrough chance, TL "level", choose-next lists, per-empire random tree) and §2 (tech lists), `js/sim/research.js` + `js/data/techs.js` (API: `Research.choices/projectCost/start/breakthroughChance/setSlider`, `Q.research(S, eid)`, orders `researchSlider/researchLock/researchEqualize/researchPick`).

## You own
`js/ui/tech.js` (screen `tech` + `MOO.UI.TechScenes`), `js/ui/techtree.js` (optional extra view).

## Screens / API
1. **`tech`** — six field tabs (Computers, Construction, Force Fields, Planetology, Propulsion, Weapons; keys 1–6) with, per field: list of researched techs (oldest first, current project last, descriptions), a picture pane for the highlighted tech (use `UI.icon` + a small procedural hologram/blueprint drawing or ship/planet render where it makes sense), the six **research sliders** (2% steps, lock by clicking the name, "=" equalises), the **light-bulb** breakthrough-chance gauge per field (`Research.breakthroughChance` — show the TRUE probability), the one-line capability summary per field (scanner range, robot controls n/col, factory waste %, terraform +n, waste elimination n/BC, ship range n parsecs …derived from `E.mods`), field LEVEL (`E.research.tl[f]`), and **Total research n RP**; the current project with progress bar (invest/cost), ETA estimate and a button to choose a project when none is set (opens the choose-next scene). Plus a modern **tech overview** tab: all 6 fields as columns of 10 tiers showing researched / available-now / locked / not-in-your-tree (unknown techs of other empires show as '?'), with search. The original's hidden randomness (each empire gets ~half the tree) should be made legible without breaking the feel.
2. **`MOO.UI.TechScenes.choose(interrupt) → Promise<level>`** — the full-screen *lab scene*: your race's scientist (`Gfx.Scenes.lab` + `Gfx.Portraits`), red caption "Choose the area of research our scientists now focus on", a list box titled "<Field> Technology" with the available techs sorted cheapest → dearest, description + cost "(510 RP)" for the highlighted item, jingle (`Audio.Music.play('research')`); returns the chosen level. `interrupt = {empire, field, choices:[{level,cost,tech}]}`.
3. **`MOO.UI.TechScenes.breakthrough(interrupt) → Promise`** — same lab: caption "<Race> scientists achieve a <Field> breakthrough", tech name + one-sentence effect, Space to continue; `interrupt = {empire, field, level, id, source:'research'|'spy'|'loot'|'trade'|'orion'}` (different caption/music for stolen/found/traded). Follow-up dialogs for slider auto-adjust after waste/eco/robotic/terraform/shield techs are optional (offer 0/25/50/75% re-balance per research/06 §5.13).
Skip-able (Space/Esc), respects `Settings.reduceMotion`. Test: `?dev=1&screen=tech&turns=40`, and call `MOO.UI.TechScenes.choose({...})` from the console with a fixture.
