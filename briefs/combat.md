## API (`MOO.Sim.Combat`)
- `findBattles(S, R) → battles[]` — after movement, every star where mutually hostile parties meet: ships of empires at war (`M.Sim.Diplo && M.Sim.Diplo.atWar(S,a,b)`; if Diplo is absent treat nobody as at war), a planet's owner vs hostile ships (a planet with bases/shield/pop is a defending party), monsters (the Orion Guardian at `S.orion` while `S.guardian.alive`; roaming monsters in `S.monsters` if present). Fleets that merely share a star with non-hostile empires do not fight. Battles happen only in orbit at a star.
- A `battle` is plain JSON: `{star, planet:{id,owner,pop,factories,bases,shield,type,special…}|null, sides:[{empire (-1 monster), fleetId, ships:[6 counts], designs:[Design.stats snapshots for slots with ships], role:'attacker'|'defender', monster?}], nebula:bool (shields off), bg, rocks:'none'|'some'|'many', attacker:empireId, human:bool, seed}`.
- `resolve(battle, R) → result` — PURE and deterministic: auto-resolve used for AI-vs-AI and for the human's **Auto** button. Implement the original's auto-resolve per §4.12 **and** the full tactical simulation with the engine's own AI playing every unit (§4.13); choose per §4.12 which the original used when; `opts.full=true` forces the tactical sim. Result: `{winner, sides:[{empire, lost:[6], survivors:[6], retreated, retreatTo}], planet:{basesLost, shieldBroken, popKilled, factoriesKilled…}, rounds, summary:[strings]}`.
- `applyResults(S, results, R)` — mutate S: remove destroyed ships from fleets, move retreating fleets (§4.11), apply planet losses, set `S.guardian.alive=false`/`killer` when the Guardian dies, push `Ev` events (`{type:'battle',…}`, news via `{type:'news', cat:'battleWon'|'battleLost'|'fleetDestroyed'|'guardianSlain', …}`), repair rules, and record who may bombard/invade this turn (`S.bombard = [{empire, planet}]`).
- Interactive tactical API for the UI (the battle screen is written by another agent against THIS contract → document it thoroughly in a header comment): `create(S, battle, R) → B` (serialisable: `{w:10,h:8,round,units:[…],planet:{…},rocks:[{x,y}],missiles:[…],log:[],order:[unit ids by initiative],active}`), `legalMoves(B, unit)`, `targets(B, unit, mode) → [{id,type,range,hitChance}]`, `act(B, unit, action)` for `{type:'move',x,y}` `{type:'fire',target,weapons}` `{type:'special',device}` `{type:'wait'}` `{type:'done'}` `{type:'retreat'}` `{type:'scan',target}` returning an ordered `events[]` for animation (`move`, `beam`, `missile-launch`, `missile-hit`, `miss`, `shield-absorb`, `armor-hit`, `ship-destroyed`, `explosion`, `planet-hit`, `base-destroyed`, `warp-out`, `special-effect`, damage numbers…), `endRound(B) → events[]`, `aiTurn(B, side) → actions[]`, `isOver(B)`, `finish(B) → result`. Hit chances shown to the player must equal the real ones.
- Worker op: `MOO.Ops.resolveBattle = function ({battle, seed}) { return Combat.resolve(battle, MOO.RNG.create(seed)); }`.

Implement EVERY rule in §4 exactly: initiative (incl. Mrrshan/Alkari bonuses), Chebyshev movement, "all weapons that reach fire", to-hit `50 − (att − def)×10` with caps, beam/missile/torpedo/bomb mechanics, shields absorbing per hit and nebula shield-off, armor-piercing, halving-shield weapons, streaming/enveloping, anti-missile/Zyro/Lightning interception, missile bases and planetary shield, special devices (stasis, pulsar, black hole, warp dissipator, technull, repulsor, cloak, teleporter…), repair specials, retreat, monsters (Guardian/Crystal/Amoeba by difficulty), colony ships/transports as non-combatants.
