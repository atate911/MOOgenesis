# Brief: describe the original game's interface from web screenshots (visual reference notes)

Goal: future developers must be able to mimic the *look and layout* of the 1993 Master of Orion interface from text alone, WITHOUT any original images being stored. Product direction: our UI should echo the original (same screen structure/flow), with an upgraded modern look (see HANDOFF.md guardrail, research/00-original-screens-notes.md for what already exists).

Method: use the built-in browser (own tab via tabs_create, pass tabId, close it at the end; front it with tabs_select before screenshots). Find screenshots on the web (Let's Play archives such as lparchive.org "Master of Orion", MobyGames, Wikipedia/Wikimedia, StrategyWiki, GOG/Steam pages, archive.org). View them; do NOT download or save any image files, do NOT commit images, do NOT copy original text beyond short labels. Describe only.

For EACH screen in your assigned group write a detailed entry: source URL(s); screen purpose; overall composition as a grid (what occupies which region, approximate % of screen width/height, left/right/top/bottom); every panel/button/label/slider/icon and its position; text labels (short, as they appear); typography feel (pixel font, case, size, colour); colour palette with approximate hex values for backgrounds, frames, bevels, text, highlights, per-slider/semantic colours, race/banner colours; framing style (bevels, borders, gradients, dithering); art content (what the central picture shows, lighting, palette); interaction cues (hover/selected/disabled states, cursor); information shown; and "to evoke this today" suggestions (what to keep, what to modernise). Be concrete about numbers (e.g. 'bottom bar ≈ 8% height, 8 equal buttons'). Native resolution was 320×200 (scaled) — give proportions as fractions.

Output: your own file under research/ui-ref/ (names below), ≤ 600 lines, markdown. Final reply ≤ 80 words (file, screens covered, gaps). No subagents.
