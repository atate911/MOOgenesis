Human players are given a prompt in the original ("Bomb?") — expose `Ground.bombPreview(S, empire, planet)` → `{pop, factories, expectedKills…}` so the UI can show it and an order `bombard {planet, yes}` stored in `S.bombard` entries (default yes for AI).
- `invade(S, landing, R) → result|null` — `landing = {empire, target, planet, n}` from `Fleet.landTransports`: run the transports gauntlet (missile bases fire; transports get the best researched armor; exposure by warp speed; Combat Transporters tech; monsters/Guardian kill all), then the land combat per the force formula (each side rolls d100 + force; loser loses one trooper; defender +5; Bulrathi +25; ties go to the defender), max 300 landing, rebels. On success: planet changes owner (`Colony` fields: pop = survivors ≤ mp3, factories kept, `operTier`=1, sliders reset to Industry 100 + ECO floor, bases/shield lost unless rules say otherwise), tech capture (2% per factory, max 6, via the same candidate rules as spying — implement `Ground.techCandidates(S, thief, victim)` and share it with the Spy module), empire death check hook, news events (`invasionSuccess/invasionRepelled`), relations incident for Diplo. Return a UI-friendly record `{attacker, defender, planet, landed, defenders, rounds:[{a:…,d:…}] (sampled for animation), survivors, captured:{factories, techs:[{field,level,id}]}, success}`.
- Also `Ground.force(S, E, isDefender)` (so the AI can estimate odds), `Ground.gauntlet(S, landing)` preview, and rebellion helpers used by the colony module (`rebels`, `unrest`; a coup when ≥ half the planets rebel — expose `Ground.coupCheck`).
