# Polish pass — October 2026 (branch `claude/polish-pass`)

Brief from the product owner: make the game look more polished on PC and phones "while retaining the soul of the game". A
screen-by-screen capture (`tools/qa/art-shots.js` at 1920x1080, `tools/qa/phone.js` in portrait / landscape / small) gave the list
below; every item is done on this branch. Nothing changes the rules, the flows or the original's layout.

## What changed, and where

| Item | Files | Notes |
|---|---|---|
| Hand cursor (PC) | `css/base.css` (`--hand`), every `cursor:pointer` in css/ and js/ui | A brass pointing gauntlet (inline SVG, hotspot 9,1) with `pointer` as fallback. `html[data-phone]` sets `--hand: pointer`, so phone.js's tap-to-read test and the phone QA still read the keyword. New code: write `cursor:var(--hand)`. |
| Colony postcard (PC) | `js/ui/side-colony.js` (`postcard`) | Under the build box: `WorldArt.colony()` picked from the colony (fortified: bases ≥ 8 or shield ≥ 10; polluted: eco readout WASTE; industrial: factories ≥ 120), a caption, and the ships in orbit (a click opens fleet deployment) plus foreign ones. The side body becomes a flex column (`:has(> .sc-post)`) so the card takes the height that is left; container queries hide the caption, then everything, when there is too little. Never on phones. |
| Turn sound + year odometer | `js/ui/galaxy.js`, `js/ui/kit.js` (`sfx:false` on `UI.button`) | `endTurn` plays `turn` once the turn really starts (the Next turn button no longer clicks as well); `newturn` still answers at turn:end. The HUD year element is kept across HUD rebuilds and the changed digits roll for 0.6 s, then it is plain text again. New / loaded games set it without a roll. |
| Save thumbnails | `js/core/save.js` (`sketch`), `js/ui/saveload.js` (`mapThumb`) | `meta.map = {w, h, d}`: 3 bytes per star (x, y, known owner's banner / explored / capital bit), base64; fog of war holds (live owner, else the last report). About 0.6 KB for 160 stars, well under the save server's 4 KB X-Save-Meta limit. Older saves have no `map` and show an empty frame. Narrow screens (≤ 900 px) get a card per slot: map, slot, leader + year, then the buttons (an empty slot's "Save here" was hidden before). |
| Boot splash | `index.html`, `js/loader.js`, `css/base.css`, `css/theme-v2.css`, `js/ui/help.js`, `js/data/text.js` | The title galaxy art behind the wordmark; a tip from `Data.text.tips` once the text module has run, never the same as last load (`moo.bootTip` in localStorage). On Simple / Easy (the tutor's difficulties) the same tip is a sticky map report on turn 0. Two tips described MOO2 (outposts, Antarans) and were replaced. |
| Research picture | `js/ui/tech.js` | `.tch-detail` gets `grid-template-rows:minmax(0,1fr)`: the canvas's own height attribute used to size the row, the canvas came out twice the panel's height and the motif sat below the visible edge. |
| Empty Report | `js/ui/races.js` | No report on file: one dossier card over the race's homeworld art with a Spy networks button, instead of six boxes reading "—". The footer hint about white techs hides with it. |
| Empire marks (colour-blind aid) | `js/core/settings.js` (`empireMarks`), `js/ui/options.js`, `js/ui/galaxymap.js` | Off by default. Owner rings take a dash pattern per banner (`RING_DASH`: blue solid, green long dashes, purple dots, red dash-dot, white double, yellow short dashes) and the race code (`RACE_CODE`: HU MR SI SA PS AL KL BU ME DA; two letters because Mrrshan/Meklar and Silicoid/Sakkra share an initial) sits beside the flag and under foreign fleets; the Colonies map key shows the patterned ring and the code. |
| Phone audience | `js/gfx/scenes.js` (`audGeo`), `js/ui/audience.js` | Portrait screens (w < 0.8 h): the leader is sized by the width and stands in the upper band above the dialogue panel; the envoy figure is not drawn there. Desktop and landscape unchanged. |
| Phone turn log | `js/ui/turnlog.js` (`counts`, `openSheet`), `js/ui/galaxy.js` (`logChip`), `css/phone.css` | A HUD chip (portrait only) with the count, red when there was fighting, amber for events; it opens the whole log in a dialog whose links close it and go to the star. Counts are cached from the log's debounced render. The in-sheet log is opaque and flush with the panel. |
| Phone map controls | `js/ui/galaxymap.js`, `js/ui/phone-galaxy.js`, `css/phone.css`, `tools/qa/phone.js` | Phones show Show all, Centre and More; More unfolds key / routes / declutter (two wide in landscape). + / − are hidden (pinch, double-tap). The HUD uses the map's full width in portrait. The QA's long-press test now picks a visible map control. |
| Landscape title | `js/ui/menu.js` | `@media (orientation: landscape) and (max-height: 520px)`: wordmark and text left, entries right. Also applies to a short desktop window. |
| Phone system view | `js/ui/system.js`, `css/phone.css` | "· in orbit" is hidden on phones (the screen is the orbit), tiles are wider and names wrap under a fixed-height picture. |
| Phone grid default | `js/core/settings.js` | `mapGrid` defaults to off when `MOO_PHONE`; Options shows the real default. |
| Install card | `js/ui/phone-galaxy.js`, `js/core/settings.js` (`phoneVisits`, `installHint`), `tools/qa/lib.js` | From the second page load in a browser tab (never standalone), once, on a quiet galaxy screen: iOS gets Share › Add to Home Screen, others the browser menu, and where Chrome fires `beforeinstallprompt` the card has an Install button. The QA harness presets `installHint` like `phoneHints`. |

## Verification

`node tools/check.js` (117 ok) · `node tools/rules-test.js` (845 passed, 1 skipped) · `node tools/qa/phone.js` portrait, `landscape`
and `small` · `node tools/qa/turns.js 40 q1 4 hard human` (no console errors) · `node tools/qa/saves.js` (server slots, which carry the
new meta) · `node tools/qa/layout-fingerprint.js` against `main`: the desktop differences are the intended ones (colony side body, save
rows, research detail, map control column). Every item was also screenshot on the affected profiles.

## Not done here

- Everything that needs new art (`ART-NEEDED.md`), the real-device pass, landscape layouts for the design editor and tool screens, the
  fleet ledger as cards (phone follow-ups 1, 2, 4).
- The hand cursor is an SVG data URI: browsers draw it at 32 px whatever the display scale, so it is crisp on a 1x screen and a little soft
  on a 2x one. A PNG `image-set()` pair would fix that if it matters.
